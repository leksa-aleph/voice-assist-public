# Для разработчиков

## Из чего состоит

Почти всё на Python. JavaScript - только мост к Discord-боту
(`discord_bridge/bridge.mjs`, Node.js): голос Discord с шифрованием DAVE
есть только в discord.js.

| Файл | Что делает |
|---|---|
| `app.py` | точка входа: журнал, Qt, окно, оверлей, трей |
| `engine.py` | распознавание: поиск речи, очереди, голоса, перевод |
| `asr_onnx.py`, `asr_parakeet.py`, `translate_onnx.py` | модели в ONNX Runtime |
| `streaming.py` | потоковая склейка текста (LocalAgreement) |
| `overlay.py` | субтитры поверх окон |
| `audio_source.py` | микрофон и звук отдельного приложения |
| `discord_bot.py` + `discord_bridge/` | Discord-бот |
| `history.py`, `file_transcribe.py` | история и расшифровка файлов |
| `ui/` | окно программы |
| `version.py` | версия |

## Запуск из исходников

Нужны Windows 11, Python 3.12, Git и Node.js 22.12+.

1. Положите папку `models` рядом с `app.py`. Проще всего скопировать её
   из установленной программы: `_internal\models`.
   Для полной сборки возьмите модели из полной установки.
2. `install.bat` создаст `venv` по `requirements-windows.lock.txt` и проверит наличие моделей.
3. Модули бота:

       cd discord_bridge
       npm ci

4. Запуск - `run.bat`.

## Сборка

    cd discord_bridge && npm ci && cd ..
    venv\Scripts\pip install pyinstaller==6.22.3
    venv\Scripts\pyinstaller voice-assist.spec --noconfirm

`node.exe` берётся из `discord_bridge\node.exe`, если он там лежит,
иначе из системного Node.js.
Для выпуска берите официальный бинарник Node.js и положите его лицензию
рядом с `node.exe` под именем `LICENSE.node.txt`. Сохраните версии Node.js
и Python вместе с данными сборки.

Установщики (Inno Setup):

    ISCC installer\voice-assist.iss
    ISCC /DVariant=ru installer\voice-assist.iss

Готовые файлы - в `installer\output`.
Если Inno Setup не может открыть файл глубоко внутри `node_modules`,
запустите сборку из короткого пути к рабочей копии.

Перед публикацией сверяйте [уведомления о лицензиях](THIRD_PARTY_NOTICES.md)
с содержимым конкретной сборки. Команда `voice-assist.exe --selftest` проверяет
распознавание, перевод и чтение WAV. Проверьте также отчёт
`%TEMP%\voice-assist-selftest.txt`: пропущенные проверки GPU и необязательных
моделей отмечаются в отчёте.

## Версия

Версия - в `version.py` и в начале `installer\voice-assist.iss`
(`AppVersion` и `Stage`); тест сверяет, что они совпадают. Для обычного
выпуска `Stage` - пустая строка.

## Модели

`tools\export_onnx.py` готовит модели в `models\onnx` (один раз, нужно
окружение с torch и pyannote). Кодировщики GigaAM и Parakeet -
`tools\export_gpu.py gigaam` и `tools\export_gpu.py parakeet`: у процессора
и видеокарты одни веса (int8 со шкалой по каналу, `*.npz`) и два графа;
видеокарта разворачивает их в fp16, процессор считает матрицы в int8.
Перевод - `tools\export_translate.py`.

## Тесты и замеры

- Тесты без моделей: `python -m unittest tests.test_core -v`.
- Плавность и нагрузка на записи: `python tools\subtitle_jumps.py файл`.
- История архитектуры и замеров - [PLAN.md](PLAN.md). Старые скрипты
  в `tools/bench` использовались с локальными записями и окружением для экспериментов.

## Подробности для любопытных

- **Пресеты «Отклика».** Быстро / баланс / экономно - примерно 0.5 / 0.6 /
  0.8 с до появления слова и 40 / 30 / 20% одного ядра. На медленном
  процессоре (меньше ×16 на одном потоке) распознаванию отдаются два-три
  потока: работы столько же, но окно готово раньше.
- **«Задержка»** - от конца слова в звуке до появления на экране (в показе
  RU - до появления перевода), медиана; в подсказке - 90% и каждый этап.
- **Английский.** Распознаёт многоязычная Parakeet, язык может меняться
  посреди разговора. Пока предложение не договорено, перевод - черновик:
  на экран идут только слова, в которых сошлись два черновика подряд.
  С видеокартой слово видно через ~0.55 с, без неё - ~0.8 с
  (Ryzen 5 7500F).
- **Видеокарта.** Если драйвер сбросил её посреди работы, распознавание
  до перезапуска программы идёт на процессоре.
- **Discord.** Пока бот в канале, захват звука Discord.exe отключается,
  чтобы не было двойных строк. Один токен - одна запущенная программа.
- **Discord RPC** (кто говорит, без бота) - только для разработки, в
  интерфейсе его нет: `%APPDATA%\voice-transcriber\discord_secret.txt`,
  две строки - Application ID и Client Secret своего приложения.
